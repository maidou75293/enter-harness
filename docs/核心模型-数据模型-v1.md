# 内核数据模型 v1

> 原则：字段只保留无法推导的；能由外部系统提供的（身份、台账原始日志）不存；
> 扩展可空、有默认值，不改变内核规则。

## 0. 实体总览

| 实体 | 作用 | 落库 | 参与记忆检索 |
|---|---|---|---|
| MemoryItem | 长期记忆 | 是 | 是 |
| Instruction | 规范 / 制度 | 是 | 否（常驻注入） |
| KnowledgeChunk | 知识块 | 是 | 是（检索） |
| Message | 对话消息 | 是 | 否（窗口） |
| Summary | 会话摘要 | 是 | 否（窗口） |
| Job | 执行记录 | 是 | 否（过程） |
| Identity | 身份 | 否 | 否（外部只读） |
| Block | 组装临时结构 | 否 | —— |

**模型共 7 个实体**：规范、画像、身份、知识、记忆、对话、执行。
其中 6 个落库；身份由账号体系提供，不落库；Block 是运行时结构，不是实体。

---

## 1. MemoryItem（长期记忆）

### 字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | text | 是 | 主键 |
| `tenant_id` | text | 是 | 租户 |
| `kind` | enum | 是 | semantic / procedural / profile |
| `scope` | enum | 是 | platform / project / user / session |
| `scope_id` | text | 是 | 范围实体 id |
| `key` | text | 是 | 断言身份；画像可为空 |
| `content` | text | 是 | 断言正文 |
| `source` | enum | 是 | user / agent / system / import |
| `status` | enum | 是 | active / superseded / archived / deleted |
| `created_at` | real | 是 | 服务端时间 |
| `content_hash` | text | 是 | 对实际注入文本计算 |
| `superseded_by` | text | 否 | 失效链指针 |
| `agent_id` | text | 否 | 归属；共享为空 |
| `session_id` | text | 否 | 会话或任务容器 |

### 约束

- 唯一有效：`(tenant_id, scope, scope_id, agent_id, kind, key) WHERE status='active' AND key<>''`；
- 失效链不成环：`superseded_by` 必须指向同租户另一条记录；
- `content` 非空；`tenant_id`、`source`、`created_at` 非空；
- 只追加：更新 = 新增 + 旧行 `superseded`。

### 索引

```text
(tenant_id, scope, scope_id, agent_id, status)
(tenant_id, key)
```

## 2. Instruction（规范 / 制度）

### 字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | text | 是 | 主键 |
| `tenant_id` | text | 是 | 租户 |
| `scope` | enum | 是 | platform / project |
| `scope_id` | text | 是 | 项目 id；platform 为空串 |
| `kind` | enum | 是 | policy / contract / role / sop |
| `content` | text | 是 | 全文 |
| `version` | int | 是 | 单调递增 |
| `content_hash` | text | 是 | 内容指纹 |
| `status` | enum | 是 | active / retired |
| `updated_at` | real | 是 | 更新时间 |
| `owner` | text | 否 | 维护人 |

### 约束

- 同 `(tenant_id, scope, scope_id, kind)` 只有一条 `active`；
- `version` 只增不减；写入必须原子 +1；
- 只有平台管理员 / 项目负责人可写；
- 超长报错或拆分，禁止静默截断。

---

## 3. KnowledgeChunk（知识块）

### 字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | text | 是 | 主键 |
| `tenant_id` | text | 是 | 租户 |
| `doc_id` | text | 是 | 文档标识 |
| `chunk_no` | int | 是 | 块序号 |
| `title` | text | 是 | 来源标题 |
| `content` | text | 是 | 块正文 |
| `source` | text | 是 | 地址/路径/抓取来源 |
| `version` | text | 是 | 来源时间 + 内容指纹 |
| `content_hash` | text | 是 | 块指纹 |
| `visibility` | enum | 是 | tenant / public |
| `review_status` | enum | 是 | pending / approved / rejected |

### 约束

- 同 `(tenant_id, doc_id, chunk_no, content_hash)` 唯一；
- 只有 `approved` 参与检索；
- `public` 必须同时 `approved`；
- 引用必须带 `title#content_hash[:8]`。

---

## 4. Message（对话消息）

### 字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | text | 是 | 主键 |
| `tenant_id` | text | 是 | 租户 |
| `session_id` | text | 是 | 会话 |
| `role` | enum | 是 | user / assistant / system / tool |
| `agent_id` | text | 否 | 发言智能体 |
| `content` | text | 是 | 正文 |
| `created_at` | real | 是 | 时间 |
| `meta` | json | 否 | 扩展信息 |

### 约束

- 只追加，不更新正文；
- 工作记忆 = 最近 N 条；超出部分进入摘要。

---

## 5. Summary（会话摘要）

### 字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | text | 是 | 主键 |
| `tenant_id` | text | 是 | 租户 |
| `session_id` | text | 是 | 会话 |
| `content` | text | 是 | 摘要 |
| `covers_from` | text | 是 | 覆盖起始消息 id |
| `covers_to` | text | 是 | 覆盖结束消息 id |
| `kind` | enum | 是 | deterministic / llm |
| `created_at` | real | 是 | 时间 |

### 约束

- 只追加；同一段消息只压一次；
- 摘要不级联（最多 2 层且指回原文）。

---

## 6. Job（执行记录）

### 字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | text | 是 | 任务 id |
| `tenant_id` | text | 是 | 租户 |
| `session_id` | text | 否 | 所属会话 |
| `parent_agent_id` | text | 是 | 父智能体 |
| `child_agent_id` | text | 否 | 子代理 |
| `status` | enum | 是 | running / done / failed / cancelled |
| `created_at` | real | 是 | 开始时间 |
| `finished_at` | real | 否 | 结束时间 |
| `output_ref` | text | 否 | 结论或产出指针 |

### 约束

- 只追加；状态单向；
- 子任务结束由父归并成 MemoryItem；
- 台账原始日志不存这里，只存指针。

---

## 7. 关系

```text
Session 1 ── n Message
Session 1 ── n Summary
Session 1 ── n Job
Job 1 ── 0..1 MemoryItem        （父归并的结论）
MemoryItem 1 ── 0..1 MemoryItem （superseded_by 自引用）
KnowledgeChunk 1 ── 0..n MemoryItem（可选指针）
Instruction 独立，按 scope 与 scope_id 匹配
Identity 外部，不落库
Block 运行时结构，不落库
```

## 8. 扩展字段（不属于内核）

| 实体 | 扩展字段 |
|---|---|
| MemoryItem | condition、status_reason、provenance、summary、outcome、expires_at、importance、confidence、use_count、last_used_at、updated_at、subtype、version、pinned |
| Instruction | effective_from、tags |
| KnowledgeChunk | tags、embedding |
| Message | 无（放 meta） |
| Summary | 无 |

扩展必须可空、有默认值，且不改变唯一约束、状态机与组装次序。

---

## 9. 明确不建的表

| 不建 | 理由 |
|---|---|
| 用户画像表 | 画像是 MemoryItem（kind=profile） |
| 决策表 | 决策是 MemoryItem（kind=semantic） |
| 记忆版本表 | 失效链 + 审计足够，不做多版本检索 |
| 块表 | 块是组装时临时结构 |
| 图谱/关系表 | 当前规模不需要 |
| 身份表 | 由账号体系提供 |

---

## 10. 最小字段的理由

| 字段 | 为什么必须在 |
|---|---|
| `tenant_id` | 多租户隔离 |
| `kind` | 决定权威与注入位置 |
| `scope` + `scope_id` | 决定可见范围 |
| `key` | 判冲突、判重复 |
| `status` | 只追加与失效 |
| `created_at` | 排序与新近度 |
| `content_hash` | 幂等与缓存 |
| `superseded_by` | 失效链可校验 |
| `agent_id` | 子代理隔离与归属 |
| `session_id` | 会话/任务溯源 |
