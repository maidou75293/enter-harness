# enter-harness 运行时框架 v1

> 定位：模型之外的运行时，负责 6 项职责。
> 原则：**LangGraph 负责「怎么跑」，我们负责「给模型看什么、记住什么、谁能看」。**
> 不重复造轮子：图执行、断点恢复、流式、多代理调度全部用 LangGraph。

## 1. 能力归属

| 能力 | 谁实现 | 说明 |
|---|---|---|
| 图执行 / 循环 | **LangGraph** `StateGraph` | 不自研执行引擎 |
| 断点 / 恢复 | **LangGraph** checkpointer | 不自研 checkpoint |
| 人工审批暂停 / 恢复 | **LangGraph** `interrupt` + `Command(resume)` | 暂停机制用它；审批策略与队列自研 |
| 流式输出 | **LangGraph** `astream` / `astream_events` | 不自研流式 |
| 子图 / 多代理调度 | **LangGraph** subgraphs / `Send` | 编排规则自研，调度用它 |
| 长期存储后端 | **LangGraph** `BaseStore`（可选） | 只当后端；schema 与规则自研 |
| 上下文拼装 | 自研 | 9 区段、预算、去重、压制 |
| 记忆模型与写入契约 | 自研 | 14 字段、R1~R5、四态写入 |
| 知识审核与引用 | 自研 | 块、版本、approved、引用格式 |
| 租户 / 身份 / 权限 | 自研 | 多租户隔离、智能体身份、最小权限 |
| 工具沙箱 / 出口控制 | 自研 | 进程、网络、路径边界 |
| 审计 / 合规 | 自研 | 留存、防篡改、可查询 |
| 评测 / 契约测试 | 自研 | 冷启动、闭环、隔离、预算 |

一句话：**LangGraph 回答「怎么跑」，不回答「上下文集什么、记什么、谁能看」。**

## 3. 六块职责

| # | 块 | 职责 | 实现 | 关键接口 | 现状 |
|---|---|---|---|---|---|
| 1 | observation | 收用户输入、工具结果、环境事件 | 自研 | `IngestPort` | 部分 |
| 2 | context | 定义、采集、选择、预算、拼装、回流、存储 | 自研 | `ContextPort` / `MemoryPort` / `KnowledgePort` | 较完整 |
| 3 | control | 图执行、循环、中断、恢复、流式 | **LangGraph** | `Agent.run` / `GraphEngine` | 有 |
| 4 | action | 工具注册、调用、审批、沙箱 | 自研 + LangChain 工具 | `ActionPort` / `AccessPolicyPort` | 部分 |
| 5 | state | 会话、检查点、记忆、恢复 | LangGraph + 自研 | `StatePort` / `MemoryPort` | 部分 |
| 6 | verification | 验收、失败恢复、审计 | 自研 | `VerifyPort` / `AuditPort` | 部分 |

## 4. 端口清单

| 端口 | 方法（最小） | 归属块 | 默认实现 |
|---|---|---|---|
| `IngestPort` | `collect(req)` | observation | `DefaultIngestPort` |
| `IdentityPort` | `resolve(req)` | 定义层 | 产品账号系统 |
| `ContextPort` | `list_blocks()` / `get_block(id)` | context | 产品块存储 |
| `MemoryPort` | `query(req)` / `upsert(item)` / `archive(ids)` | context / state | `StoreMemoryPort` |
| `KnowledgePort` | `search(query, top_k)` / `get_chunk(id)` | context | 知识库适配器 |
| `AccessPolicyPort` | `can(identity, action, target)` | action | 产品权限系统 |
| `ActionPort` | `list_tools()` / `call()` / `request_approval()` / `resume()` | action | `ToolActionPort` |
| `StatePort` | `load()` / `save()` / `checkpoint()` / `resume()` / `list_checkpoints()` | state | `SQLiteStatePort` |
| `VerifyPort` | `check(result, criteria)` | verification | `RuleVerifyPort` |
| `AuditPort` | `emit(event)` / `query(filter)` | verification | `SQLiteAuditPort` |

已有 5 个：`IdentityPort`、`ContextPort`、`MemoryPort`、`KnowledgePort`、`AccessPolicyPort`。
新增 5 个：`IngestPort`、`ActionPort`、`StatePort`、`VerifyPort`、`AuditPort`。

## 5. 一次运行

```text
1. 定义层加载：规范/红线 · 身份 · 画像
2. Ingest：用户消息、会话、记忆、知识、工具结果
3. Context：选择 → 预算 → 拼装
4. LangGraph：进入图执行，模型拿到拼好的上下文
5. 模型要调工具 → Action Gateway：
     白名单 → 策略 allow/ask/deny → 沙箱 → 执行 → 结果回图
     需要人工 → interrupt 暂停 → 审批 → Command(resume) 恢复
6. 模型给出最终回答
7. Verification：验收 → 失败重试/补偿/升级
8. 回流 → 归一存储 → 下一轮采集可见
9. 全程 trace / audit / metrics
```

## 7. 不造轮子 / 必须自建

**不造轮子：**

- 图执行、条件边、并行 super-step → LangGraph；
- 断点、恢复、时间旅行 → LangGraph checkpointer；
- 人工暂停 → LangGraph interrupt；
- 流式 → LangGraph streaming；
- 多代理调度 → LangGraph subgraphs / Send；
- 向量库、模型 SDK → 现成后端。

**必须自建：**

- 记忆 schema 与写入契约；
- 上下文 9 区段、预算、去重、压制；
- 租户隔离、智能体身份、最小权限；
- 知识审核与引用；
- 工具审批、沙箱、出口；
- 审计留存与合规；
- 契约测试与评测集。

## 9. 验收

1. 6 块职责各有一个 owner，端口齐全；
2. 冷启动：记忆为空仍能运行；
3. 闭环：上一轮写入下一轮可见；
4. 租户 / 范围不匹配不进入上下文；
5. 预算超限可见失败，不输出半段；
6. 审批可暂停并恢复；
7. 断点可恢复，不重跑已完成节点；
8. 每条注入内容可追到 `source` 与 `content_hash`；
9. 审计日志留存可查；
10. 删除旧实现后，契约测试全部通过。
