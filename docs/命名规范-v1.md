# enter-harness 命名规范 v1

> 目标：看到名字就知道「这是端口、默认实现、app 适配器，还是业务对象」。

## 1. 端口（Protocol）

| 规则 | 示例 |
|---|---|
| 治理端口一律以 `Port` 结尾 | `IdentityPort` / `ContextPort` / `MemoryPort` / `KnowledgePort` / `AccessPolicyPort` / `IngestPort` / `ActionPort` / `StatePort` / `VerifyPort` / `AuditPort` |
| 基础端口同样以 `Port` 结尾 | `ModelPort` / `StorePort` / `AgentStorePort` / `PolicyPort` |
| 事件出口是历史例外 | `EventSink`（已有契约，暂不改；新代码用 `AuditPort`） |
| 禁止无后缀的治理接口名 | ~~`AuditSink`~~ → `AuditPort`（保留别名过渡） |
| 同名概念必须带领域前缀 | `ToolPolicyPort`（工具风险） / `AccessPolicyPort`（数据访问）；旧 `PolicyPort` 仅保留别名 |

## 2. 默认实现 / 适配器

格式：**`{Backend}{Concept}Port`**。

| 名称 | Backend | 说明 |
|---|---|---|
| `SQLiteStatePort` | SQLite | 状态 + 检查点 |
| `SQLiteAuditPort` | SQLite | 审计哈希链 |
| `SQLiteKnowledgePort` | SQLite | 知识块 |
| `StoreMemoryPort` | Store | `MemoryPort` 查询契约 |
| `MarkdownMemoryPort` | Markdown | 人可读写的记忆文件 |
| `MarkdownKnowledgePort` | Markdown | 人可读写的知识块 |
| `PostgresMemoryPort` | Postgres | 记忆记录 |
| `PostgresKnowledgePort` | Postgres | 知识块 |
| `PostgresStatePort` | Postgres | 状态 + 检查点 |
| `PostgresAuditPort` | Postgres | 审计哈希链 |
| `StoreStatePort` | Store | app `graph_snapshots` → `StatePort` |
| `MemoryContextPort` | Memory | 记忆 → 上下文块 |
| `ToolActionPort` | Tool | 工具 + 审批 |
| `RuleVerifyPort` | Rule | 规则验收 |
| `StaticIdentityPort` | Static | 静态身份目录 |
| `DefaultIngestPort` | Default | 输入归一 |

app 侧实现统一 **`App{Concept}Port`**：

- `AppMemoryPort`
- `AppAccessPolicyPort`（旧 `AppAccessPolicy` 保留别名）

## 3. 模块命名

| 文件 | 内容 |
|---|---|
| `harness/ports.py` | 所有协议，只放契约 |
| `harness/types.py` | 跨端口数据类型 |
| `harness/constants.py` | 状态枚举 |
| `harness/{concept}.py` | 该概念的主实现 / 默认实现（`ingest/action/state/verify/audit/memory/context/knowledge/identity`） |
| `harness/{backend}_{concept}.py` | 同一概念的其它后端（`markdown_memory.py` / `postgres_audit.py` 等） |
| `harness/factory.py` | 本地后端工厂（`build_local_ports`） |
| `harness/wiring.py` | 装配检查 |

不用 `*_adapter.py` 后缀；适配器身份由类名表达。

## 4. 数据类型

| 后缀 | 用途 | 示例 |
|---|---|---|
| `*Input` | 进入内核的原始数据 | `RawInput` |
| `*Result` | 一次操作的结果 | `ActionResult` / `WriteResult` |
| `*Event` | 可审计事件 | `AuditEvent` |
| `*Ticket` | 需要人工处理的单据 | `ApprovalTicket` |
| `*Verdict` | 判定结论 | `Verdict` |
| `*Checkpoint` | 可恢复的状态点 | `Checkpoint` |

领域层已有的 `ToolResult` / `RunResult` / `ExecutorOutcome` 保持原名，不强行合并。

## 5. 字段命名

| 规则 | 示例 |
|---|---|
| 标识符一律 `*_id` | `tenant_id` / `user_id` / `agent_id` / `session_id` / `thread_id` / `run_id` / `trace_id` |
| 时间戳一律 `*_at` | `created_at` / `updated_at` / `decided_at` / `last_used_at` |
| 禁止裸 `at` | `AuditEvent.at` / `RawInput.at` 仅保留为兼容属性，新代码用 `created_at` |
| 范围字段固定三件套 | `scope` / `scope_id` / `tenant_id` |

app 边界使用 `tenant`，进入内核前必须映射成 `tenant_id`；不要让 `tenant` 出现在端口签名里。

## 6. 方法动词

| 动词 | 语义 | 示例 |
|---|---|---|
| `get_*` | 按 id 取单个对象 | `get_block` / `get_chunk` |
| `list_*` | 列元数据，不读正文 | `list_blocks` / `list_tools` / `list_checkpoints` |
| `query` | 按条件过滤记录 | `MemoryPort.query` |
| `search` | 按相关性检索 | `KnowledgePort.search` |
| `upsert` | 追加或取代 | `MemoryPort.upsert` |
| `archive` | 归档，不物理删除 | `MemoryPort.archive` |
| `collect` | 采集原始输入 | `IngestPort.collect` |
| `emit` | 写一条事件 | `AuditPort.emit` |
| `check` | 只判定，不修复 | `VerifyPort.check` |
| `load` / `save` | 整体状态读写 | `StatePort.load` / `save` |
| `checkpoint` / `resume` | 存点 / 从点恢复 | `StatePort` |
| `request_approval` / `resume` | 审批单 / 审批后恢复 | `ActionPort` |

不要用 `do_*` / `handle_*` 这类无领域含义的动词做端口方法。

## 7. 状态枚举（`harness/constants.py`）

| 常量 | 取值 |
|---|---|
| `ACTION_STATUSES` | `ok / partial / error / denied / needs_approval` |
| `RUN_STATUSES` | `ok / partial / failed / cancelled / blocked` |
| `WRITE_ACTIONS` | `append / supersede / noop / invalid` |
| `APPROVAL_STATUSES` | `pending / approved / rejected / expired` |
| `REVIEW_STATUSES` | `pending / approved / rejected / archived` |
| `AUDIT_DECISIONS` | `start / ok / failed / pending / approved / rejected / error` |

业务自定义状态放产品侧，不进内核常量。

## 8. 兼容别名（过渡期）

| 旧名 | 新名 |
|---|---|
| `AuditSink` | `AuditPort` |
| `SQLiteAuditSink` | `SQLiteAuditPort` |
| `PolicyPort` | `ToolPolicyPort` |
| `AppAccessPolicy` | `AppAccessPolicyPort` |
| `AuditEvent.at` | `AuditEvent.created_at` |
| `RawInput.at` | `RawInput.created_at` |

别名至少保留一个版本；新代码只允许使用新名。
